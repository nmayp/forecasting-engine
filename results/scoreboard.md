# Benchmarks: the engine against open foundation models

Same locked holdout, same strict reference, same scoring for every engine (lab v2). Skill = pooled skill against the reference (0 = as good as the reference). Each foundation model is its best fair variant: own history, every layer as covariates as known at the origin (where the model takes covariates: Chronos-2 and TiRex-2; Toto 2.0 has no covariate input yet), cross-country context, or the causal parents only. A layer counts as won only if the engine beats the best of the three. Most champions are ensembles that include open models (Toto 2.0, FlowState, Chronos-2 or TiRex-2 forecasts as members, next to the engine's own trees); a blend that contains the best open model counts as a win only if it beats that model alone on the holdout. Generated by `python -m forecasting_engine.lab.scoreboard`.

Looks = holdout looks the family has used so far (each one a selection on the holdout; since 20 Oct 2026 a candidate gets one only after beating the champion on development and on most of its time blocks). Many looks make a small holdout lead weaker.
